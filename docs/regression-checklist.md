# Regression checklist

Прогнати після кожної фази плану 0001. Бекенд: локально `http://127.0.0.1:8000/api`.
Для кожної сторінки також: немає помилок у консолі, сайдбар підсвічує поточний пункт.

## Каркас (усі /admin/*)
- [ ] Сайдбар: 10 пунктів (Графік навчання, Дашборд, Предмети, Викладачі, Групи, Потоки, Аудиторії, Навчальні плани, Обмеження, Розклад), активний підсвічений
- [ ] Toast успіху/помилки показується; модалки відкриваються/закриваються (хрестик, Скасувати)

## Дашборд — /admin/
- [ ] Лічильники: викладачі, предмети, групи, аудиторії, навантаження на тиждень, семестри (`/stats/`)
- [ ] Картка поточного семестру: назва, дати, прогрес
- [ ] Без поточного семестру — стан «немає активного семестру»
- [ ] Календар поточного місяця відмальовується

## Семестри — /admin/semesters/
- [ ] Список семестрів завантажується; поточний — зірка ★, підсвічений рядок
- [ ] Додати семестр (назва, дати) зберігається
- [ ] Додати з увімкненою генерацією: слоти часу (додати/видалити), вихідні (Сб/Нд за замовчуванням), виключені/включені дати
- [ ] Редагувати семестр: форма заповнена поточними значеннями
- [ ] Видалити семестр (підтвердження)
- [ ] Зробити поточним (☆ -> ★)
- [ ] Редагування семестру з уже згенерованим розкладом: з'являється попередження «Увага!», Скасувати нічого не зберігає
- [ ] Підтвердження попередження («Так, видалити та змінити») зберігає з `confirm_schedule_deletion`
- [ ] Редагування семестру без розкладу зберігає без попередження
- [ ] Кнопка «Згенерувати розклад» запускає генерацію, показує результат/помилку

## Деталі семестру — /admin/semesters/detail.html?id=
- [ ] Інфо про семестр і конфігурація (слоти, вихідні, виключені дати)
- [ ] Статистика слотів
- [ ] Календар за місяцями, перемикання ← / →
- [ ] Клік по дню відкриває бічну панель з датою і слотами дня
- [ ] Додати слот зі списку часу семестру (`POST /timeslots/`)
- [ ] Видалити слот (🗑️) з панелі
- [ ] Закрити панель; для дня без слотів — повідомлення «немає пар»

## Предмети — /admin/subjects/
- [ ] Список, пошук за назвою
- [ ] Додати / редагувати (назва, опис з лічильником символів) / видалити

## Викладачі — /admin/teachers/
- [ ] Список, пошук
- [ ] Додати викладача; у режимі додавання предмети збираються локально і зберігаються разом
- [ ] Редагувати: список призначених предметів
- [ ] Призначити предмет (select лише з непризначених) — `manage_subjects`
- [ ] Прибрати предмет (confirm)
- [ ] Видалити викладача

## Групи — /admin/groups/
- [ ] Список, пошук; курс обчислюється з року вступу
- [ ] Додати / редагувати / видалити

## Потоки — /admin/streams/
- [ ] Список потоків із групами
- [ ] Додати/редагувати потік: чекбокси груп (відмічені при редагуванні)
- [ ] Видалити потік

## Аудиторії — /admin/rooms/
- [ ] Список, пошук
- [ ] Додати / редагувати (назва, місткість, тип) / видалити
- [ ] Модалка «Типи аудиторій»: список, додати тип (назва, опис), видалити тип
- [ ] Новий тип одразу з'являється у select форми аудиторії

## Навчальні плани — /admin/study-plans/
- [ ] Список планів
- [ ] Фільтри: семестр, група, викладач (список перезавантажується)
- [ ] Додати план: семестр, предмет, тип заняття, години, тип аудиторії
- [ ] Вибір предмета підвантажує лише викладачів цього предмета (`/teachers/?subjects=`)
- [ ] Перемикач цілі: група / потік / курс (зайві поля ховаються і очищаються)
- [ ] Редагувати існуючий план (поля заповнені, викладач вибраний)
- [ ] Видалити план

## Обмеження — /admin/constraints/
- [ ] Список; фільтр за семестром
- [ ] Додати обмеження: семестр, тип (Вихідний день, Макс. пар на день, Матриця часу, Ланцюжок пар)
- [ ] Зміна типу перемальовує конструктор конфігурації
- [ ] Ланцюжок пар: ціль примусово «global», вимкнена; підтягує навчальні плани обраного семестру
- [ ] Інші типи: тип цілі -> список цілей (викладач / група / аудиторія / потік) підвантажується
- [ ] Редагувати обмеження (конфігурація та ціль відновлені)
- [ ] Видалити обмеження

## Розклад — /admin/schedule/
- [ ] Вибір семестру завантажує сітку та пари
- [ ] Навігація по тижнях (‹ ›), підпис тижня
- [ ] Колонки Субота/Неділя відображаються, коли для них є слоти
- [ ] Картка пари: предмет, група/потік, викладач, аудиторія, тип (колір лекція/практика/лаб)
- [ ] Drag & drop пари в інший слот; конфлікт -> повідомлення, пара повертається
- [ ] Перетягнути в «Нерозміщені» (лічильник змінюється)
- [ ] Замок 🔒/🔓: закріплена пара не перетягується
- [ ] Клік по парі: модалка з деталями; зміна аудиторії (select, вимкнений для закріплених)
- [ ] «Згенерувати розклад» для обраного семестру

## Публічна сторінка — /
- [ ] Дати автоматично заповнюються з поточного семестру
- [ ] Пошук викладача: дропдаун підказок (debounce), вибір
- [ ] Пошук групи: підказки (fallback на повний список), вибір ставить `groupId`
- [ ] Фільтр за курсом
- [ ] Фільтри дат від/до
- [ ] Порожня форма -> попередження «заповніть хоча б одне поле»
- [ ] Результати згруповані за днями, відсортовані за датою і парою; бейдж типу, час, аудиторія
- [ ] Порожній результат -> «No lessons found»; помилка сервера показується
