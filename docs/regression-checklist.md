# Regression checklist

Прогнати після кожної фази плану. Бекенд: локально `http://127.0.0.1:8000/api`.
Для кожної сторінки також: немає помилок у консолі, сайдбар підсвічує поточний пункт, тема (світла/темна) не ламає вигляд.

## Каркас (усі /admin/*)

- [ ] Сайдбар: «Головна», «Задачі», «Семестр»; група «Довідники» — «Викладачі», «Групи», «Потоки», «Аудиторії», «Предмети»; група «Планування» — «Навчальні плани», «Обмеження», «Розклад»
- [ ] Активний пункт підсвічений, заголовок сторінки й крихти відповідають розділу
- [ ] Перемикач теми у верхній панелі змінює світлу/темну тему; після перезавантаження вибір зберігається
- [ ] Toast: успіх, помилка, попередження; закривається хрестиком; toast з дією («Скасувати», «Повернути») виконує дію
- [ ] Drawer (Семестр, Календар, Деталі заняття): Esc і клік по затемненню закривають, фокус повертається на кнопку-відкривач
- [ ] Inline-підтвердження (видалення, зміна поточного семестру): «Скасувати» нічого не змінює, Esc закриває

## Головна — /admin/

- [ ] Привітання в заголовку за часом доби; під ним дата й тиждень семестру (якщо семестр триває)
- [ ] Картка «Як працює система»: три етапи; «Зрозуміло, сховати» прибирає її, кнопка «Як це працює?» повертає
- [ ] Без поточного семестру — картка «Оберіть поточний семестр» з посиланням на список семестрів
- [ ] Картка семестру: назва, статус «Підготовка»/«Розклад згенеровано», «N з 5 етапів готово», смуга етапів (Календар, Ресурси, Плани, Обмеження, Генерація), поточний етап виділений
- [ ] «Наступний крок» відповідає першому незавершеному обовʼязковому етапу; посилання веде на потрібну сторінку/вигляд
- [ ] Блок уваги: кількість блокерів/попереджень, посилання «Задачі»; без блокерів і попереджень його немає
- [ ] «Найближчі дати»: початок/завершення семестру та сьогодні, відносні підписи, прогрес тижня
- [ ] «Ресурси семестру»: 4 плитки (викладачі, групи, аудиторії, предмети) з кількістю, часткою «мають предмет/план/викладача» і статусом; клік веде на довідник (з `?filter=` для проблемних)

## Задачі — /admin/tasks/

- [ ] Семестр береться з `?semester=` або поточний; без семестру — стан із посиланням на семестри
- [ ] Готовність до генерації: відсоток пройдених перевірок; за наявності блокерів не перевищує 50 % і це написано
- [ ] KPI «Блокує / Погіршує / Поради» з кількістю перевірок і записів
- [ ] Групи задач за severity, «Пройдено» окремо; список довший за 6 записів згортається («Показати всі», «Згорнути»)
- [ ] Виправлення просто в списку: «Призначити викладача» / «Додати предмет» — вибір, «Зберегти», список перевірок оновлюється
- [ ] Після виправлення toast з «Скасувати» повертає призначення
- [ ] «Зараз у корпусі» показує поточні пари (предмет, група/потік, тип, аудиторія); поза парами блок схований
- [ ] «Завантаженість аудиторій»: тижнева сітка, ‹ › в межах семестру (на краях вимкнені), легенда 0–4 і підпис «N пар»
- [ ] Немає занять на тижні — повідомлення, а не порожня таблиця

## Семестр — /admin/semesters/

- [ ] `?list=1` — список семестрів: назва, період, бейдж «Поточний»; без поточного — попередження
- [ ] «Новий семестр»: назва, дати; порожні обовʼязкові поля підсвічуються, дата кінця раніше за початок не зберігається
- [ ] «Згенерувати часові слоти» показує вихідні дні (кнопки днів), розклад дзвінків (додати/прибрати пару), виключені та включені дати
- [ ] Створення й редагування зберігаються; у списку є «Зробити поточним» з inline-підтвердженням
- [ ] Редагування семестру з наявним розкладом: попередження про видалення розкладу, «Скасувати» нічого не зберігає, «Так, видалити та змінити» зберігає
- [ ] `/admin/semesters/detail.html?id=N` перенаправляє на `/admin/semesters/?id=N`
- [ ] Огляд: етапи (Календар, Ресурси, Плани, Обмеження, Генерація) з підписами; поточний етап виділений
- [ ] Передперевірка: заголовок із кількістю блокерів/попереджень/порад, список перевірок, посилання дій, кнопка «Перевірити ще раз»
- [ ] За наявності блокерів кнопка «Згенерувати» вимкнена з поясненням; без блокерів — активна
- [ ] «Навчальні плани по групах»: смуга готовності, рядки груп із кількістю планів або «немає планів», посилання на плани
- [ ] «Календар»: «Про семестр», статистика слотів, сітка місяця з ‹ ›, підсвічені дні з парами, вихідні, дні поза семестром
- [ ] Клік по дню відкриває drawer: пари дня, додавання пари зі списку дзвінків, видалення пари з inline-підтвердженням
- [ ] «Редагувати» в календарі відкриває ту саму форму семестру; «Видалити семестр» — inline-підтвердження і повернення до списку
- [ ] Генерація: підтвердження з кількістю занять, які буде видалено, і заблокованих, які залишаться; результат у toast

## Викладачі — /admin/teachers/

- [ ] Master–detail: пошук за ПІБ або предметом, фільтр «Без предметів», вибір рядка, лічильник у підвалі
- [ ] Deep link `?id=N` відкриває викладача; `?filter=no-subjects` вмикає фільтр; вибір рядка оновлює URL
- [ ] Створення: «Додати викладача» → рядок Draft → ПІБ; створення запису проходить, коли заповнити поля Tab-ом і піти з поля
- [ ] Введення в полі під час збереження не губиться; «Зберігаю…» → «Збережено», помилка підсвічує поле
- [ ] Предмети: чипи з хрестиком; комбобокс «Додати предмет…» (стрілки, Enter, Esc, клік); додати предмет, поки триває збереження, — чип не губиться
- [ ] Прибрати предмет: toast із «Повернути» відновлює призначення
- [ ] «Доступність»: перемикач семестру, сітка дні × пари, клік по клітинці — недоступна пара, по дню — вихідний; зміни зберігаються, легенда збігається
- [ ] «Веде в групах» для вибраного семестру: чипи груп/потоків ведуть на їхні сторінки
- [ ] Видалення — inline-підтвердження, після нього вибрано сусідній запис

## Групи — /admin/groups/

- [ ] Master–detail: пошук за назвою, фільтри «Без плану» та курси, групування за курсом, кількість студентів у рядку
- [ ] Deep link `?id=N` і `?filter=no-plan`; вибір рядка оновлює URL
- [ ] Створення через Draft: назва, кількість студентів, рік вступу; створення проходить після заповнення всіх полів Tab-ом і виходу з поля
- [ ] Введення під час збереження не губиться; відʼємні/порожні значення не зберігаються
- [ ] Після створення зʼявляються «Поточний курс», «Потоки», «Навчальний план», «Розклад» з робочими посиланнями
- [ ] «Навчальний план групи» веде на плани з `?group=&semester=`; чипи потоків — на сторінку потоку
- [ ] Видалення через inline-підтвердження

## Потоки — /admin/streams/

- [ ] Master–detail: пошук за потоком або групою, фільтр «Без груп», підпис «N груп · M студ.»
- [ ] Deep link `?id=N`; вибір рядка оновлює URL
- [ ] Створення через Draft: назва; створення проходить після Tab-у з поля
- [ ] Чипи груп: назва веде на групу, кількість студентів, хрестик; комбобокс додавання (стрілки, Enter, Esc)
- [ ] Додати групу, поки триває збереження, — група не губиться і не дублюється
- [ ] Прибрати групу: toast із «Повернути»; зміни складу зберігаються після перезавантаження
- [ ] Видалення потоку не видаляє групи

## Аудиторії — /admin/rooms/

- [ ] Master–detail: пошук за номером, корпусом, типом, приміткою; фільтри за типами, групування за корпусом, місткість у рядку
- [ ] Deep link `?id=N`; вибір рядка оновлює URL
- [ ] Створення через Draft: назва, корпус, тип, місткість, примітка; кнопка «Створити аудиторію» (порожні поля підсвічуються, Enter у полі створює)
- [ ] Підпис під назвою оновлюється під час введення (корпус, тип, місця); введення під час збереження не губиться
- [ ] «Типи аудиторій»: список із кількістю використань; назва/опис редагуються в рядку й зберігаються
- [ ] Додавання типу одразу зʼявляється у фільтрах і в select відкритої аудиторії
- [ ] Видалення типу, який використовують аудиторії, показує зрозумілу помилку; видалення вільного типу проходить після підтвердження
- [ ] Видалення аудиторії через inline-підтвердження

## Предмети — /admin/subjects/

- [ ] Master–detail: пошук за назвою або описом, фільтр «Без викладача», кількість викладачів у рядку
- [ ] Deep link `?id=N`; вибір рядка оновлює URL
- [ ] Створення через Draft: назва, опис; без назви запис не створюється, після назви й Tab-у — створюється
- [ ] Введення в описі під час збереження не губиться
- [ ] Після створення зʼявляються «Викладачі» (чипи ведуть на викладача) і «Де використовується» (якщо предмет є в планах)
- [ ] Видалення через inline-підтвердження

## Навчальні плани — /admin/study-plans/

- [ ] Master–detail: у списку групи й потоки, пошук за назвою, предметом або викладачем, фільтр «Без плану», групування «Групи»/«Потоки»
- [ ] Deep link `?item=gN|sN` і `?semester=N`; вибір семестру в шапці перезавантажує список, URL оновлюється
- [ ] Вибір рядка відкриває план; для потоку показані чипи його груп
- [ ] «Додати предмет» додає рядок Draft; предмет → викладач підвантажується лише для цього предмета й увімкнений тільки після вибору предмета
- [ ] Рядок зберігається, коли заповнені предмет, тип, викладач, кількість і тривалість; неповний запис підсвічує поля
- [ ] Для групи з курсом вибір «усіх груп N курсу» створює записи для курсу й показує, скільки створено/пропущено
- [ ] Зміна поля наявного рядка зберігається (повний PUT), кількість «записів · пар» у заголовку оновлюється
- [ ] Введення під час збереження не губиться; повторні швидкі зміни не перезаписують одна одну
- [ ] «Скопіювати план з іншої групи»: пошук групи-джерела, попередження про пропущені дублікати, копіювання й оновлення списку
- [ ] Видалення запису та рядка Draft («Скасувати») працюють; видалення наявного — inline-підтвердження

## Обмеження — /admin/constraints/

- [ ] Master–detail: пошук за ціллю або правилом, фільтри за цілями (Викладач, Група, Аудиторія, Потік, Глобальне), групування за цілями
- [ ] Deep link `?id=N` і `?semester=N`; перемикач семестру в шапці перезавантажує список і знімає вибір
- [ ] Створення через Draft: ціль (картки) → обʼєкт (комбобокс лише для викладача/групи/аудиторії/потоку) → тип → параметри
- [ ] Вибір цілі «Глобальне» примусово ставить тип «Ланцюжок пар»; вибір іншої цілі прибирає його
- [ ] Редактор «Вихідний день»: кнопки днів вмикаються/вимикаються
- [ ] Редактор «Матриця часу»: сітка днів × пар із семестру, клік по клітинці й по дню; без розкладу дзвінків — стан «немає розкладу дзвінків»
- [ ] Редактор «Макс. пар на день»: степер 1–10, підпис «N пар на день»
- [ ] Редактор «Ланцюжок пар»: вибір опорного й залежного планів, розрив; показує підсумок «план A → план B»
- [ ] Перемикач «Активне»: вимкнене правило лишається в списку з позначкою «вимкнене»
- [ ] Зміна семестру в самій формі зберігає обмеження і перемикає сторінку на цей семестр
- [ ] Кожен крок зберігається автоматично; неповне правило не зберігається і показує підказку, чого бракує
- [ ] Видалення через inline-підтвердження

## Розклад — /admin/schedule/

- [ ] Вибір семестру завантажує сітку й пари; тиждень починається з тижня найранішої пари
- [ ] ‹ › змінюють тиждень, підпис періоду правильний; «Оновити» перезавантажує
- [ ] Колонки Субота/Неділя є лише тоді, коли для них є слоти
- [ ] Фільтр «Усі / Група / Викладач / Аудиторія» + вибір значення звужує пари
- [ ] Картка пари: тип, предмет, група/потік, викладач, аудиторія; «Нерозподілені» з лічильником
- [ ] Drag & drop пари в інший слот зберігається; помилка сервера повертає картку і показує toast
- [ ] Перетягування в «Нерозподілені» прибирає пару зі слота й збільшує лічильник
- [ ] Замок: закріплена пара не перетягується і має вимкнені поля в drawer
- [ ] Клік/Enter по парі відкриває drawer деталей; зміна аудиторії зберігається, «Скасувати» не змінює
- [ ] «Згенерувати»: спершу перевірки; блокери показують toast із посиланням на семестр, без блокерів — підтвердження з кількістю занять
- [ ] Під час генерації видно лоадер із журналом; після завершення сітка оновлюється

## Публічна сторінка — /

- [ ] Пошук групи/викладача: підказки з підписом типу, стрілки/Enter/Esc, клік вибирає
- [ ] Фільтр курсу звужує групи й ховає викладачів із підказок
- [ ] `?g=<id>` і `?t=<id>` відкривають розклад; «Поділитися» копіює посилання
- [ ] «Зберегти як мій розклад» запамʼятовує вибір; на старті він відкривається автоматично, скидання працює
- [ ] «Зараз» показує поточну пару з прогресом і «ще N хв», «Далі» — наступну; без пар блоки сховані
- [ ] Стрічка днів: кількість пар, сьогодні виділено; клік вибирає день
- [ ] ‹ › тижні, «Сьогодні», перехід до дати; вигляд «День»/«Тиждень»
- [ ] Розклад дня: час, предмет, викладач або група, аудиторія, бейдж типу; вікна між парами; минулі/поточні пари позначені
- [ ] Порожній тиждень: підказка й перехід до найближчих пар, якщо вони є
- [ ] «Додати тиждень у календар (.ics)» завантажує файл; на порожньому тижні — попередження
- [ ] Перемикач теми працює; помилка завантаження довідників показує стан із «Оновити»
