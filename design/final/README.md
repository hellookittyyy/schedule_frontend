# Фінальні кандидати UI

Збережено 19.11.2026. Залишилось два варіанти, з яких буде обрано один (або зібрано гібрид).

| Файл | Що це |
|---|---|
| [triad.html](triad.html) | **Тріада**: сланець, шавлія й пісок. Темне меню, тепле світле тло, акцент шавлії, три пастельні відтінки для блоків |
| [mosaic.html](mosaic.html) | **Мозаїка**: 6 кольорів. Кожен розділ меню і кожен блок має свій колір, кнопки нейтрально-чорні |
| [backlog.md](backlog.md) | Відкладені ідеї. Перша — блок «Сьогодні / Зараз іде» для розкладу лаборанта |
| [tokens.css](tokens.css) | Точні значення кольорів обох варіантів для світлої та темної теми (без `color-mix`), плюс спільні токени форм і шрифту |

## Що спільне

- **Структура UX.** Обрана комбінація:
  - головна — зрозуміла точка входу:
    - як працює система;
    - стан семестру з наступним кроком;
    - ресурси семестру (викладачі, групи, аудиторії, предмети);
    - останні зміни;
    - найближчі дати;
  - задачі — окремий екран, а на головній лише один компактний рядок про них;
  - довідники — «список + деталі» без модалок;
  - семестр — кроки з передперевіркою;
  - публічна сторінка — «мій розклад» з карткою «зараз / далі».
- **Форми «Чорнила»:**
  - шрифт Commissioner;
  - радіус 12px;
  - тонкі рамки;
  - темна колонка меню і світла робоча зона.
- **Теми.** Світла й темна, перемикаються кнопкою у верхній панелі, вибір запам'ятовується в браузері.
- **Контраст.** Перевірено розрахунком: основний текст не нижче 8.7:1, другорядний текст і бейджі не нижче 4.5:1.

## Як переглядати

Сторінки самодостатні: стилі й скрипти вбудовано в сам файл, зовнішні лише шрифти Google. Тому їх можна відкрити напряму з диска або через локальний сервер:

```bash
py -m http.server 5500
```

Далі відкрити `http://localhost:5500/design/final/triad.html`. Чорна панель унизу перемикає екрани: «Головна», «Задачі», «Викладачі», «Семестр» і «Студент». Ця панель лише для прототипу. Параметр `?t=dark` у посиланні одразу відкриває темну тему.

## Звідки взялось

Ці файли — знімки з `design/ui-variants/15-slate-lab.html` (`?p=triad` і `?p=x-mosaic`). Подальші експерименти в `ui-variants/` на них не впливають.

## Наступний крок

1. Обрати один варіант або гібрид.
2. Перенести його токени з `tokens.css` у [`design/ui-kit/ui-kit.css`](../ui-kit/ui-kit.css), в змінні `--ui-*`.
3. Верстати справжні сторінки адмінки та публічної частини за обраною структурою UX.
