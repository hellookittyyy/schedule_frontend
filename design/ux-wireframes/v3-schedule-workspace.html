Варіант 3 · Робочий простір розкладу

Ідея: головний екран адмінки — це сам розклад, і решта підлаштовується під нього. Ліва панель вибирає, чий розклад дивимось (група / викладач / аудиторія) і показує нерозподілені пари. У центрі сітка тижня. Права панель — інспектор вибраного: заняття, викладач або слот. Під час перетягування система одразу підсвічує, куди можна поставити пару, а куди ні.

Для кого: людина, яка вручну доводить розклад після автогенерації і тримає в голові багато залежностей.

Карта сторінок

Адмінка
  • Робочий простір /admin (головна) нове
    • Ліва панель: лінза (Група · Викладач · Аудиторія) + список + «Нерозподілені»
    • Центр: тиждень · день · порівняння двох груп
    • Інспектор: заняття / викладач / слот / конфлікт
    • Верхня панель: семестр, ⚡ генерація, ↺ undo, історія змін
  • Дані (бічна шухляда, не окремі сторінки): Викладачі · Групи/потоки · Аудиторії · Предмети · Плани · Обмеження
  • Налаштування семестру: календар, дзвінки
Публічна частина
  • Та сама сітка у режимі читання з тими самими лінзами
  • Мобільний: список дня замість сітки
  • /view?lens=room&id=301 — «де вільна аудиторія» нове

Дашборд зі статистикою прибрано: корисні цифри (конфлікти, нерозподілені) показані прямо в робочому просторі.

Оцінка

👍 Плюси

  • Мінімум переходів: усе на одному екрані
  • Найкраще для ручного доведення розкладу
  • Одна сітка для адмінки й публіки
  • Найсильніше «вау» для курсової

👎 Мінуси

  • Складний фронтенд: стан, DnD, підсвітка слотів
  • Потрібен API «вільні слоти для заняття»
  • Погано на мобільному (адмінка лише для ПК)

🎯 Коли обирати

  • Генерація дає 90%, а решту доводять руками
  • Головна мета — швидкість роботи диспетчера
