Структура UX: 5 варіантів

Мінімальний UI (сірі вайрфрейми), фокус на структурі сторінок, навігації та сценаріях. Кожен варіант — клікабельний прототип: червоні номери відповідають жовтим приміткам, а пунктирні елементи клікабельні. Візуальний дизайн (концепції 01–04 і UI Kit) можна накласти на будь-яку обрану структуру.

Що зараз (аналіз)

Поточна карта сторінок
  • Публічна: форма пошуку (викладач, група, курс, з дати, по дату)
  • Адмінка (10 пунктів меню, всі на одному рівні):
  • Графік навчання (семестри) — стоїть першим
  • Дашборд — лічильники + календар
  • Предмети
  • Викладачі
  • Групи
  • Потоки
  • Аудиторії
  • Навчальні плани
  • Обмеження
  • Розклад (DnD)
Знайдені проблеми UX
  1. Немає порядку роботи. Щоб підготувати семестр, треба обійти 5–6 сторінок і пам'ятати послідовність. Система не підказує, чого бракує.
  2. Інформацію розірвано. Обмеження викладача лежать не в профілі викладача, а на окремій сторінці, де його треба знову шукати у випадаючому списку. Те саме з потоками й планами групи.
  3. Модалки скрізь, навіть для складних форм. Семестр — це модалка з дзвінками, вихідними та святами, які вводяться як «YYYY-MM-DD» у textarea. Обмеження — модалка з динамічним конструктором конфігурації.
  4. Дашборд нічого не каже. Лічильники «42 викладачі» не допомагають ухвалити жодне рішення.
  5. Конструктор не попереджає. Чи можна поставити пару в слот, дізнаєшся лише після помилки сервера (409).
  6. Публічна сторінка вимагає забагато. 5 полів щоразу, вибір не запам'ятовується, немає посилання на розклад групи, немає «що зараз / що далі».
  7. Немає масових дій та імпорту. Паралельні групи заповнюються вручну, по одній модалці на запис.
  8. Немає скасування. Видалення через «Ви впевнені?» без undo. Генерація перезаписує розклад без версій.

Варіанти

Варіант 1

Майстер семестру

Покроковий процес: календар → ресурси → плани → обмеження → генерація → публікація. З прогресом і передперевіркою.

 Варіант 2

Профілі сутностей

Сторінка викладача / групи / аудиторії з вкладками. Обмеження й плани живуть там. Глобальний пошук. Публічні профілі.

 Варіант 3

Робочий простір розкладу

Розклад як головний екран: лінзи (група / викладач / ауд.), інспектор, підсвітка вільних слотів, виправлення конфліктів.

 Варіант 4

Список і деталі

Один шаблон з трьох панелей для всіх довідників. Без модалок, з мультивибором, масовими діями, імпортом та обмеженнями-реченнями.

 Варіант 5

Задачі + Ctrl+K

Головна — список проблем із виправленням в один клік. Командна палітра. Для студентів: «мій розклад» і сповіщення.

Рекомендація

Варіанти можна комбінувати, бо вони відповідають на різні питання. Реалістичний план для курсової:
  1. Каркас — варіант 4 (список і деталі) для всіх довідників. Найменше переписування, прибирає модалки, дає один шаблон.
  2. Головна адмінки — варіант 5 (задачі) замість дашборда з лічильниками. Ctrl+K додати пізніше.
  3. Семестр — спрощений варіант 1: сторінка семестру з чеклістом кроків і передперевіркою перед генерацією.
  4. Публічна частина — з варіантів 2 + 5: одне поле пошуку, посилання /g/КН-31, запам'ятований «мій розклад», картка «зараз / далі».
  5. Варіант 3 — як наступний етап для екрана «Розклад» (підсвітка слотів та інспектор).
